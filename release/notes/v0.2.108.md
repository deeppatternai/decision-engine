# Decision Engine v0.2.108

## Added

- Added TRAE Desktop integration on Windows, with product and version checks before configuring its MCP connection.
- Added a Doctor client selector for checking one Agent integration alongside the common Decision Engine checks.
- Added runtime-free Audit and Visual plugin source packages and marketplace entries for supported Agent hosts. Their package builders include MIT license notices in generated portable, Cowork, and Harness archives.

## Changed

- Managed auto-update now requires an explicit opt-in. When enabled, the launcher discovers and stages signed updates in the background during a session and applies a staged update after that session ends, for use on the next Agent start.
- Revoked a historical test release-verification key in the client trust table so it can no longer authorize new installations or updates.

## Fixed

- Fixed Stopper audit details so authorized auditor identity and timing survive status-only final polls, while cached details are cleared if debug access is revoked.
- Fixed Doctor skill-route checks for Codex and Claude Code installations that have no configured Decision Engine MCP entry.
- Improved Windows installer guidance when a detected Agent adapter is unavailable or remains unconfigured.

## Known limitations

- Existing managed installations do not receive automatic updates until `auto_update` is explicitly set to `true` in their device configuration.
- Older installations that only trust the retired test key need a separately verified update or reinstall path.
- Plugin source publication does not deploy the remote endpoints or publish host plugin releases; those remain separate steps.
