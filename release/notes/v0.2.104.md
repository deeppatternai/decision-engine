# Decision Engine v0.2.104

## Added

- Added managed Doctor entrypoints for macOS, Linux, and Windows that use the installer-managed Python environment and support human-readable or JSON diagnostics.
- Added preliminary installer support for recognized Arch Linux and Omarchy desktop systems, with Omarchy aarch64 acceptance-tested and x86_64 pending native-device acceptance.
- Added DeepSeek Harness integration through its Cordis configuration, with user Skills, native display windows, and Audit Stop Panel support.
- Added Xiaomi MiMo integration through managed JSONC updates that preserve surrounding user configuration, with user Skills, native display windows, and Audit Stop Panel support.
- Added host-specific uninstall cleanup for the new DeepSeek Harness and Xiaomi MiMo integrations while preserving unrelated user configuration.

## Changed

- Installed-user diagnostics now direct users to the managed Doctor commands instead of requiring a system Python invocation.

## Fixed

- Fixed Windows bootstrap validation so a source/checkout mismatch stops installation without modifying the existing managed state.
- Fixed uninstall cleanup for active integrations so owned host entries are removed without treating unrelated host configuration as managed state.

## Known limitations

- Arch-family installation is acceptance-tested on Omarchy aarch64; the implemented x86_64 path remains pending native-device acceptance.
- DeepSeek Harness and Xiaomi MiMo support core MCP, Skills, native display windows, and the Audit Stop Panel, but do not expose popup follow-up.
