# Decision Engine v0.2.103

## Added

- Added live audit-status shimmer rows to the native Stopper surfaces so queued and running reviews show progress while the panel is active.
- Improved recovery from leftover uninstall state created by older managed Windows installations.

## Changed

- Windows installation and update flows now discover registered Git for Windows installations and validate the selected installation before use.
- Qoder IDE and Qoder CN IDE host detection now recognizes their ACP identity, and WorkBuddy AI display routing preserves the host-specific MCP integration.
- The local shim retains unknown audit outcomes so an ambiguous request can be retried without being treated as completed.

## Fixed

- Prevented WebView close handling from blocking the caller while preserving the native popup shutdown path.
- Aligned the macOS Stopper binaries with the CI-produced artifacts and strengthened Windows entrypoint integrity coverage.
- Improved cross-platform native GUI and Stopper regression coverage for the updated progress, routing, and recovery behavior.

## Known limitations

- Native progress windows still require a supported desktop and WebView environment; activation and hosted audit availability remain separate prerequisites.
- Unsigned or otherwise untrusted custom Windows Git binaries remain unsupported by the secure installer path.
