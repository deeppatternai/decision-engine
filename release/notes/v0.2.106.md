# Decision Engine v0.2.106

## Added

- Added decimal GE Chat pricing support so fractional credit amounts are validated, displayed, and preserved across the popup request lifecycle.
- Added Xiaomi MiMo graphic-request progress keepalive behavior to keep long-running server rendering requests alive.

## Changed

- Updated developer and WorkBuddy AI skill-route migration to preserve unrelated user-owned routes while moving managed routes to the current installation.
- Extended host lifecycle and uninstall ownership handling for Xiaomi MiMo and WorkBuddy AI configurations.

## Fixed

- Fixed GE Chat HTTP 429 handling so free-quota, free-budget, and rate-limit business errors remain visible to users instead of becoming generic transport failures.
- Fixed Windows Git trust validation with bounded probes and stable verdict handling across installer and CI checks.
- Fixed uninstall ownership recovery for verified developer integrations so managed entries can be removed without claiming unrelated host configuration.

## Known limitations

- Decimal GE Chat prices are bounded by the client wire contract and remain subject to the service's credit and quota policies.
- Xiaomi MiMo native graphic display supports progress keepalive, but popup follow-up remains unavailable.
- Windows Git trust probing fails closed when signature validation is unavailable, times out, or returns an untrusted verdict; installation then requires a trusted Git installation or administrator repair.
- Uninstall and route migration preserve entries whose ownership cannot be proven instead of removing them automatically.
