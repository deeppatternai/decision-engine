# Decision Engine v0.2.105

## Changed

- Improved selection of Graphic Explanation for natural-language requests for flowcharts, architecture diagrams, mind maps, and other visual explanations.
- Added automated Windows entrypoint integrity checks covering installation and uninstallation contracts.

## Fixed

- Kept Xiaomi MiMo Graphic Explanation calls active with MCP progress notifications when the host supplies a supported progress token, and bounded status polling by the remaining request deadline.
- Corrected WorkBuddy AI Skills placement while respecting explicit destination overrides and preserving routes used by legacy WorkBuddy installations.
- Improved migration from verified development-checkout Skills routes to managed installation routes without replacing unrelated directories or arbitrary links.
- Recognized verified development-checkout integrations during uninstall, including Xiaomi MiMo configuration, while retaining ownership checks.
- Stabilized Windows Git signature verification with a bounded probe and more specific diagnostics for untrusted or unavailable Git executables.
- Distinguished daily free-usage limits and temporary free-service budget limits from generic rate-limit errors in popup chat, with localized messages.

## Known limitations

- Xiaomi MiMo progress keepalive depends on the host supplying a supported MCP progress token; it does not remove the overall Graphic Explanation request deadline.
