# Decision Engine v0.2.107

## Changed

- Audit status windows now preserve meaningful elapsed-time display during transient polling interruptions and show a local connection-timeout failure after a prolonged outage.

## Fixed

- Fixed audit detail payload validation so malformed or unsupported detail data is rejected without corrupting the displayed run state.
- Updated the macOS Stopper source and packaged arm64/x86_64 binaries together.
- Fixed Codex launcher startup so skill-route repair runs only when Decision Engine ownership of the MCP registration is verified.

## Known limitations

- A prolonged service or network outage is shown locally as a connection-timeout failure; the underlying hosted audit may still require a later status check when connectivity returns.
- Codex skill-route repair preserves existing routes when MCP ownership cannot be proven.
