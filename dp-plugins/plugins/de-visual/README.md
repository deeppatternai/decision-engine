# Deep Pattern Visual

Runtime-free plugin for hosted diagrams, infographics, and comics. Every host
connects to the isolated Visual resource at
`https://endpoint.deeppattern.ai/plugin/mcp/v1/visual`; OAuth credentials stay
in the host credential store.

The protected Web viewer is the cross-host baseline. Compatible MCP Apps hosts
also receive an inline status card. Generated bytes are delivered only through
the private App channel or the authenticated viewer, never in model-visible
tool text.

The plugin does not include Python, Node, a native executable, activation code,
device token, access token, refresh token, or client secret.
